# API Reference

The complete Poweradmin API v2 surface, generated from the controller annotations in the
Poweradmin source. Every endpoint, parameter, request body and response schema is listed here -
this page is the specification, not a summary of it.

For how the API works as a whole - enabling it, the two authentication schemes, versioning and
error conventions - start with [API Overview](overview.md) and
[Authentication](authentication.md). [Endpoints](endpoints.md) groups the same operations by task
if you would rather browse than search.

> **Note:** The spec below documents API **v2**. It is regenerated from the source for each
> release, so it describes the current release line. A running instance can also serve this
> interactively at `/api/docs` when `api.docs_enabled` is true.
